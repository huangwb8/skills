# 优化计划（A1）: auto-test-skill 会话初始化脚本增强

**计划ID**: v202601121151  
**目标**: 让 `scripts/create_test_session.py` 更贴合本 skill 的“可追溯文档 + 轻量测试会话”交付要求，减少手工初始化与不一致。  
**范围**: `auto-test-skill/scripts/create_test_session.py`

---

## 本轮问题清单（按优先级）

### P0（必须修复）

1) **会话初始化缺少“可选生成 plans/ 计划文档骨架”的能力**
- **位置**: `auto-test-skill/scripts/create_test_session.py`
- **影响**: A/B 轮开始阶段容易遗漏 `plans/v*.md` 或 `plans/B轮-v*.md`；计划文档与测试会话目录无法“一键成套”落盘。
- **修复**:
  - 新增 `--create-plan`：缺失时生成 `plans/{id}.md` / `plans/B轮-{id}.md`
  - A 轮使用 `templates/OPTIMIZATION_PLAN_TEMPLATE.md`；B 轮使用 `templates/B_ROUND_CHECK_TEMPLATE.md`
- **验证**:
  - `--create-plan` 生成计划文档文件且默认不覆盖

### P1（强烈建议）

2) **测试报告初始内容与模板体系不一致**
- **位置**: `auto-test-skill/scripts/create_test_session.py`
- **影响**: `templates/TEST_REPORT_TEMPLATE.md` 存在时也不会被使用，导致初始化输出风格不统一。
- **修复**: 若 `templates/TEST_REPORT_TEMPLATE.md` 存在则优先用模板生成，否则回退到内置简版。
- **验证**: 创建会话后 `tests/{session}/TEST_REPORT.md` 来自模板（或回退文本）。

### P2（可选）

3) **模板占位符无法自动填充，增加手工编辑成本**
- **位置**: `auto-test-skill/scripts/create_test_session.py` + `auto-test-skill/templates/TEST_PLAN_TEMPLATE.md`
- **影响**: 每轮都要重复填充 `TEST_ID` / 路径 / 关联文档路径等字段。
- **修复**: 在模板写入时替换最关键字段（如 `{{TEST_ID}}`、`{{TARGET_SKILL_ROOT}}`、`{{PLAN_DOC_PATH}}` 等）。
- **验证**: 新建会话后 `tests/{session}/TEST_PLAN.md` 中关键字段已被替换。
