# Skill 身份 demo 的兼容性验证

当前优先级是维持旧 Skill 和尚未确证身份的 Skill 的安装与使用。身份能力先在隔离目录验证；本任务不把生产 Skill 转为严格安装，不修改系统安装副本、默认信任或宿主加载方式。

## 验证顺序

1. 审查普通安装、bootstrap、远程安装、快速更新与严格入口的分支及依赖。
2. 运行既有安装器和身份库测试，建立当前代码基线。
3. 增加公开入口回归：身份依赖不可用；无配置、无身份、未确证或残缺声明；安装、重复安装、更新、dry-run、双平台默认安装与安装后的脚本执行。
4. 验证同目录混有受管记录时的行为，保留防降级保护，明确批量更新限制。
5. 复核新测试的隔离边界，运行最终定向回归，记录结果与 BAC。

## 判定边界

测试结果只支撑实际覆盖的平台与入口。合成脚本执行不等于全部 Skill 业务通过，也不证明模型真实选用和加载；模拟下载不等于联网服务验收。若混合部署改变现有批量更新行为，记录为推广阻塞项，继续使用独立测试目标，不能据此宣称正式目录零影响。
