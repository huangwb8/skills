## [1.0.1] - 2026-11-14

### Added

- `bsi init [--config-dir DIR]` 与 `initialize_publisher`：统一 `remote.env`、`bsi-keys/root.pem`、`bsi-keys/release.pem`，独立生成 Ed25519 密钥，配置只保存三项公开值与两条私钥路径。
- 重复运行核验复用，完整密钥对可恢复缺失的公开配置；部分材料、冲突、坏 PEM、链接和不安全权限明确拒绝，不覆盖或自动换钥。初始化加锁、独占创建私钥、原子追加配置及检测外部编辑，不回显私钥/配置/路径。
- 新增 36 项默认/自定义布局、身份独立性、权限、并发、失败恢复、CLI 脱敏及真实签名验证链路回归；包内共 112 项通过，Ruff 和隔离 wheel 无关工作目录/默认 HOME 首次生成与重复复用验证通过。双语 README 与身份协议同步，测试私钥已清理。本次按用户指定版本纳入 1.0.1 发行。

### Changed

- Python 发行版本对齐 1.0.1；双语 README 更新 PyPI 安装命令、包版本查询和发布者初始化用法，移除未发布提示。协议保持 v1，签名域、信任与安装判定不变。

## [0.1.0] - 2026-11-14

### Added

- 独立身份声明、受签发行、显式信任与有限撤销、精确依赖锁定 API/CLI。
- 完整文件集合、字节和执行属性核对，路径/文件类型与输入限额。
