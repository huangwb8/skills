# Citation truth and fit

Review normalized `subject_context`, `source_metadata`, and `source_excerpt`
evidence. Assess source identity, entailment, and appropriateness. This verifier
is intentionally instruction-only: an agent or domain engine performs the
semantic review and emits the standard result protocol.
