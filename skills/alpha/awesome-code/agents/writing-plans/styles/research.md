# 科研计划（research）

计划供人阅读、讨论和决定下一步。开头用一小段白话说明研究对象、眼下知道什么、还差哪一步证据，以及补上这块证据有什么价值。必要时用具体场景帮助理解。专业术语首次出现时说明它在本研究里的作用，公式、代码和命令放在读者确实需要的地方。

## 科学问题

把核心问题写成一句可以用数据回答的话。根据需要交代研究对象或适用范围、要比较的情况、主要观测指标和时间范围。用少量背景说明问题从何而来，区分已经观察到的现象、已有证据和仍待验证的推断。问题的措辞要与拟用证据匹配，例如只有观察性比较时，先问二者是否相关。

## 科学假设

给出有依据、能被结果推翻的判断。说明为什么提出它、预期看到什么，以及什么观察会削弱它。效应方向能从已有证据或机制推导时就写清楚，方向未知时如实写明。存在能产生类似结果的解释时，写出实验如何区分它们，或哪些解释目前仍无法排除。纯探索性任务可以提出候选假设或明确要估计的量，标明哪些判断将在看到数据前确定，哪些发现需要之后用独立数据验证。

## 子问题

将主问题和假设拆成几个能各自作答的子问题。每个子问题都要说明它需要哪一类证据、能为主问题补上哪一环。可按现象是否存在、在不同条件下能否复现、竞争解释能否区分等角度拆解，按研究需要取舍。每个子问题应有自己的判读标准，允许其中一项出现相反或不确定结果时仍解读其他项。说明确实存在的先后依赖。若多项分析复用同一批样本或同一指标，交代共享证据的范围，避免把多次分析当作多份独立验证。

## 实验与分析设计

按子问题组织实验或分析。每项设计给出以下四部分。一个子问题需要多项实验时，说明每项各自补充什么证据。用已有数据、模拟或公开数据集也按这四部分写。

1. **实验目的**。说明要回答哪个子问题、检验哪部分假设，以及这项结果会影响什么判断。
2. **实验方法**。说明用什么数据或样本、比较谁与谁、观察什么、怎么分析，以及为什么这套设计能回答问题。只展开会影响判断的细节，例如分析单位、纳入条件、对照或基线、主要指标、样本量或精度依据、偏倚控制和复现安排。尽量在查看结果前确定会影响结论的分析选择和判断标准。关键条件未知时写明如何核实。数据来源、样本规模与方法参数以已知信息为准。
3. **预期实验结果**。用读者能理解的观察描述假设成立时会看到什么，再说明出现相反结果、没有明显差异或估计不够精确时分别如何解释。适用时给出有依据的效应量、区间或判断阈值。预期以条件句写，事实层只写已有观察。
4. **实验局限性**。点出最可能改变结论的偏倚、测量局限、替代解释或外推范围。说明能通过什么检查减轻问题，以及检查后还有哪一部分无法判断。

## 结果如何合在一起

说明各子问题的证据如何共同回答主问题。交代主要证据与补充证据各承担什么作用，它们一致、冲突或不足时分别能得出多强的结论。机制、因果、预测和相关性是不同的主张，结论强度以设计实际能提供的证据为限。给出可观察的完成标准，例如交付哪些效果估计、图表和复核记录，以及如何记录空结果和不确定性。完成标准适用于任何结果方向。

## 实施安排

按真实依赖安排数据或材料准备、主要分析、必要的复核与汇总。复杂项目再写资源、时间、关键风险与备选路径。只有会改变可行性或解释的技术细节才需要进入正文。简单计划可以合并这一节和结果判读，交代最低限度的准备、验证和交付即可。

## 默认计划结构

默认用下面的结构撰写。每个子问题用一个小节，把它要提供的证据与对应实验写在一起。若一个子问题需要多项实验，在该小节内分别交代每项实验的四个部分。短计划可以合并最后两节。

```markdown
# <研究主题>科研计划

## 为什么要做这个研究

用一小段白话说明研究对象、已有发现、缺少的证据，以及回答这个问题有什么价值。

## 科学问题

用一句话提出主问题。按需要交代研究对象、比较条件、主要观测指标和时间范围。

## 科学假设

说明为什么提出这个假设，预期看到什么，以及什么结果会削弱它。若研究以探索为主，写明要估计什么或比较哪些可能的解释，并说明哪些发现需要独立验证。

## 子问题与实验设计

### <第一个可以独立回答的子问题>

用一句话说明它为主问题补哪一块证据。

#### 实验目的

说明这项实验或分析要检验什么，结果会影响哪项判断。

#### 实验方法

写清数据或样本从哪里来、比较谁与谁、观察什么、怎么分析，以及这样设计的理由。

#### 预期实验结果

说明哪些观察支持或削弱假设，以及怎样识别证据不足。判断取决于效应大小或精度时，写明有依据的标准。

#### 实验局限性

说明最可能影响解读的因素、可做的检查和检查后仍需保留的疑问。

## 如何综合判断

说明各子问题的证据怎样回答主问题。写清证据一致、冲突或不足时，各自允许得出什么结论。涉及共享样本或关键依赖时，交代它如何影响判断。

## 实施顺序与完成标准

按实际依赖列出准备、主要分析、复核和汇总的顺序。写清计划结束时要交付的结果与记录，包括空结果或不确定结果。列出会影响可行性的待确认事项，以及确认办法。
```

## 写法示例

**问题与假设**。在同一城市的热浪期间，树冠覆盖较多的街区午后是否更凉？如果树冠与局地降温相关，那么在建成环境相近的街区之间，覆盖较多的街区午后气温应更低。

**先问关联是否存在，再问能否复现**。第一项比较同一轮热浪中建成环境相近的监测点，估计午后温差。若温差接近零且估计足够精确，预期关联在该条件下缺乏支持。第二项按事先固定的办法在留出的监测点和热浪时段复核，观察方向和差值是否接近。若只在最初样本中出现差异，就把结论限定在已观察的地点和时段。附近水体、遮挡或监测点选址仍可能影响读数，两项结果一致也只能支持观察性关联。

## 交付前检查

- 只读开头和科学问题，读者能否说清研究要弄明白什么，以及为什么值得做？
- 每个假设能否被具体观察削弱？每个子问题是否提供可单独解读、与主问题相关的证据？
- 每项实验或分析是否写清目的、方法、预期结果和局限性？结果相反或证据不足时，读者是否仍知道怎么判断？
- 数据、方法、时间和资源是否匹配？未知前提是否有核实办法？结论边界、交付物和完成标准是否清楚？
