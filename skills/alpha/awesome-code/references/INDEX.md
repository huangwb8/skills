## 使用说明

1. **按需加载**：AI 只在需要时加载具体文档，减少 context window 消耗
2. **渐进式披露**：从 SKILL.md 概述开始，深入时再查阅参考文档
3. **关键词触发**：在对话中提到相关关键词时，自动加载对应文档
