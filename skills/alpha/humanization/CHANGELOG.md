# Changelog — humanization

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [1.3.1] - 2026-10-18

### Added（新增）

- 新增“边界声明压缩”分支：从“定义 + 多个否定排除项”中恢复正向研究判断，每段默认只保留一个会改变解释的必要限定。
- 诊断输出新增“正文保留的限定 / 建议删除或合并的限定”处置表，并补充可比性、前期结果、真实科学二分及安全 token 四类回归样例。

### Changed（变更）

- 将连续“不能证明/不等同于/仍需验证”优先合并；保留关系保持与临床获益等真实科学边界，不新增方法、指标或结论。
- 质量检查配置新增 `require_boundary_disposition_table`，用于要求边界处置可复核。

## [1.3.0] - 2026-10-08

### Changed（变更）

- 正式目录、frontmatter、配置名称和使用示例更名为 `humanization`；保留 NSFC 润色范围、参数、参考资料及保护规则。
- 不保留 `nsfc-humanization` 源目录；自然语言润色请求和安装参数保留旧名兼容，安装器将旧名解析为 `humanization`，只安装正式目录。
- 补齐目标和输入输出、校验、失败恢复说明，并同步仓库公共约束块；README 不再重复记录当前版本号。

## [1.2.0] - 2026-08-25

### Added（新增）

- 将机器味诊断扩展为词语、句法、段落和章节四层，新增工程协议腔、规格书句法、无主语流程句、混合语域、术语漂移、跨章节去重和人类感反向检查。
- 新增术语表与“保留/改写/合并/人工确认”处置分类，区分受控 token、需释义术语和临时造词。
- 新增安全不变量提取与改写后对照流程，保护状态/权限、阈值、分母、暂停/失败处理、探索性定位及规划资源边界。
- 新增匿名研究内容与风险应对回归样例，并将默认策略、章节职责和质量检查键集中到 `config.yaml`。

### Changed（变更）

- 重写 `SKILL.md` 工作流，要求先做章节职责和事实首次定义扫描，再逐行润色；自评明确分为自然度/章节职责轮与语义/结构安全轮。
- `config.yaml` 版本更新至 1.2.0；保留原有参数名和输出模式。

## [1.1.2] - 2026-06-22

### Added（新增）

- 明确将“不是……而是…… / 并非……而是…… / 不只是……更是……”等伪对立、整齐二分句式纳入高优先级机器味识别对象。
- `SKILL.md` 新增二分转折句分类处理规则：区分真实边界、伪对立和同义递进，分别采用弱化边界、拆掉对称骨架或合并重复概念的改写策略。
- `references/machine-patterns.md` 补充“不是……而是……”句式的判断要点、可用处理和禁止新增事实提醒。

## [1.1.1] - 2026-06-22

- 同步更新 `SKILL.md`、`README.md` 与 `config.yaml` 中的默认参数和版本号口径。

## [0.4.0] - 2026-02-24

### Added（新增）

- 新增可选控制参数：`section_type`（章节类型）/ `field`（领域）/ `strength`（强度）/ `output_mode`（输出模式）/ `self_eval_rounds`（自评轮数上限）
- 新增 `output_mode=diagnosis_only`：仅输出机器味诊断报告（模式 + 严重程度 + 建议设置）
- 新增 `output_mode=text_with_change_summary*`：支持输出“变更摘要”（用于快速核查语义保留）
- 新增 STYLE_CARD（风格卡）：为跨段落一致性提供可复用的“风格约束”，支持用户在后续批次粘贴回传

### Changed（变更）

- 更新 `SKILL.md`：补齐 D2/D3/D4/D5/D7 的可操作机制（领域/章节感知、强度参数化、变更摘要、STYLE_CARD 一致性）
- 更新 `references/machine-patterns.md`：新增 `field` 的领域表达偏好提示，支持“模式库 + 领域框架”联动
- 更新 `config.yaml` / `README.md`：版本号更新至 0.4.0（单一真相来源）
