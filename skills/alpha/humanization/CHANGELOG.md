# Changelog — humanization

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [1.5.0] - 2026-11-01

### Changed（变更）

- 定位改为通用语言润色，覆盖文章、邮件、报告、说明、学术与技术文本；已有文本的润色请求无需点名 Skill 或显式选择风格。
- 默认风格改为 `auto`，按用途、读者、语气和原文适配，线索不足时使用 `general_prose`；新增通用文字和职场沟通风格。旧名与旧参数继续兼容，`nsfc_academic` 仅映射正式学术表达，不自动加载基金章节路径。
- 同步执行规则、中英文指南与参考资料；将语义保护扩展到沟通意图、请求、承诺、责任和日期/金额，补充 R–V 通用样例与触发反例。
- 明确英文普通词语可编辑；现有检查器对英文词、百分号和货币符号的保守处理采用人工比对路径，不以脚本差异冻结正常润色。

## [1.4.0] - 2026-11-01

### Added（新增）

- 新增可复用的正向自然写作参考：思想组织、句段推进、篇章承接、节奏、必要解释、作者感和语域均有正反例。
- 新增显式 `style_profile`：NSFC 为默认，一般学术、自然解释和技术说明仅在明确调用并选择对应风格后启用；不改变全局对话设置。
- 新增 `structure_mode`：默认保持行段；显式 `reflow_plain` 仅允许连续纯文本重分段，保护结构区域回退保留。
- 新增标准库只读字面保护检查器及 37 项仓库公开入口测试；明确其不能证明语义安全，不支持的复杂输入返回未检查。
- 扩展回归资料 G–Q，提供八维评价、原文/旧/新版匿名比较、优秀原文免改和人工评审入口；同步中英文使用指南。

### Changed（变更）

- 流程改为理解内容、诊断表达、整体组织、语言润色、语义核对和原稿比较；无净改善时保留原文。
- 移除段首观点句和每段限定数量要求；逐项保留独立科学边界，纠正可比性样例中分布、阈值与获益边界可合并删除的错误暗示。
- 默认 `strength` 改为 `moderate`、`self_eval_rounds` 改为两轮；保留既有参数/取值与旧名，一轮也必须覆盖表达和安全核对。摘要默认精简，详细审计表按需展开。

### Validation（验证）

- 37 项保护器测试、5 项旧名/隔离安装回归通过；strict 结构与公共约束检查通过。测试先发现并修复了波浪线代码围栏的漏判。
- 同宿主独立生成五组旧/新稿，第三个独立上下文进行匿名八维评审：新版相对旧版 1 胜、4 平、0 负；胜例为独立推断边界表达，原文在该例与新版平局。十份生成稿的字面保护检查均通过。另实测三种非 NSFC 语域及五项输入/恢复边界。
- 上述只覆盖一次采样的合成短文与 Agent 评审，没有人工认可、跨模型验证或长篇质量结论；不能据此声称新版普遍更自然。完整评估与局限见仓库 `docs/plans/2026-11-01-humanization-natural-writing.md` 及本轮任务记录。

## [1.3.1] - 2026-10-18

### Added（新增）

- 新增“边界声明压缩”分支：从“定义 + 多个否定排除项”中恢复正向研究判断，每段默认只保留一个会改变解释的必要限定。
- 诊断输出新增“正文保留的限定 / 建议删除或合并的限定”处置表，并补充可比性、前期结果、真实科学二分及安全 token 四类回归样例。

### Changed（变更）

- 将连续“不能证明/不等同于/仍需验证”优先合并；保留关系保持与临床获益等真实科学边界，不新增方法、指标或结论。
- 质量检查配置新增 `require_boundary_disposition_table`，用于要求边界处置可复核。
