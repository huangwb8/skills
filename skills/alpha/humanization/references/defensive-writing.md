# 防御性表达：按信息功能判断

目标是让原稿真正表达的判断清楚出现，压缩无信息的免责和假想反驳，同时保全必要限定。不把果断当作准确，不要求第一句必须是结论，也不按否定词数量判断质量。叙事、论证铺垫和独立阅读所需的重复可以保留。

## 五个判断问题

对具体句段依次核对：删除会改变事实、证据强度、适用范围、责任、阈值、风险理解或下一步决策吗？限定来自原稿哪个位置，还是候选自行添加？它回应了作者真实主张或问题，还是反驳未提出的极端解释？同一阅读单元是否已经承载该含义，合并后还能独立理解吗？能否把同一含义写成清楚的主张、已有依据和必要边界，而不是仅删除“不”“可能”？

按内容功能分为 necessary（必要）、redundant（重复）、anticipatory（假想反驳）、performative（姿态式免责）、mixed（真实信息混杂包装）、unresolved（证据不足）。处置为 keep/compress/rewrite/delete/human_review。必要和混合片段保留功能；删除仅针对已证明没有独立信息的包装。unresolved 保留原句并转人工判断，不能借改写增强结论。

主 Agent 编辑后，审查者独立回答“作者究竟主张什么、依据在哪里、允许推断到哪里”，不先接受主 Agent 的诊断。只对可定位、可解释危害且重要的残留给 fail；弱、孤立、有合理用途的表达可 pass 附建议。不得为了满分重复改写。

## 论证与篇章的补充检查

五问也适用于整段论证和篇章，无须逐句填表。按实际问题检查回应对象、主张可见性、对立关系、判断回避和篇章平衡；这些是帮助理解的视角，沿用上面的信息功能分类，不新增五项评分或必填记录。先找到原文实际支持的判断及依据，再看限定是否遮蔽了它；合理铺垫、结论位于段末或出现否定词，均不能单独作为缺陷依据。“不是……而是……”须先判断两者是真实互斥、互补还是主次关系，再决定是否改写。

**判断回避。** 对照原文已经作出的选择、比较及确定性等级。若候选用泛泛的“各有利弊”“仍需综合考虑”替换了明确判断，指出丢失的是哪项选择或比较，并恢复它及原有适用条件。原文暂不作判断、证据不足或确有无法消解的权衡时，应保留这种开放性；不能替作者选边，也不能把表达更直接写成证据更强。明确判断的丢失同时属于语义保真问题，仍须由 revision-readiness 独立核对。

**篇章平衡。** 在已提供的上下文中，检查连续段落是否推进主张与依据，还是反复回应同一个假想反方。指出重复承担的功能及它如何打断理解；保留不同对象、证据范围、决策条件与章节独立阅读所需的限定。不能按限定占比、否定词数量或固定重复次数裁决。默认在原行段内压缩；若修复需要删除整段或跨段搬移，遵循结构权限，仅在获准的纯文本区域重排。上下文不足以判断重复用途时保留，并说明缺口。

## 保留与修改的反例

| 原文片段 | 处理与理由 |
| --- | --- |
| 我们观察到跨中心关联。需要强调，这并不意味着我们解决了所有分型问题。 | 未讨论“所有分型问题”时可删后句；关联主张仍保留，不升级为因果 |
| 关联仅在内部队列验证；未作外部验证，也未评估临床获益。 | 三项独立范围均保留；相邻不意味着重复 |
| 项目比较三个平台，但并不是要证明所有平台完全一致。项目也不声称平台没有任何差别。 | 核对实际研究目标；同一排除重复时合并，不新增等效性结论 |
| 可能有效，但样本仅含成人；出现呼吸困难应立即就医。 | 保留不确定性、人群与危险信号；不是免责噪声 |
| This estimate may be biased because follow-up was incomplete. | 保留 may 和失访原因；扫描命中不能判失败 |
| The supplier must notify the customer within 10 days; liability is limited to direct loss. | 告知义务、期限与责任范围都不能因“法务腔”删除 |
| 先声明本说明不能替代任何专业建议，再重复两次同一泛化免责。 | 先核对告知义务与使用场景，只合并无独立功能的重复，不一概删法律文本 |

## 审查与有界修订

专项审查覆盖原文、候选和全部附件；线索扫描不完整，必须通读，没有关键词也可能存在主张被无关铺垫掩盖或假想反驳。候选新增范围、否定、承诺或未经支持的事实同样是问题。必要限定必须在正文相应主张中存续，仅写进摘要不算保全。

每个问题记录来源/候选锚点、类别、处置、重要性理由、保全功能及候选去向。阻塞性意见还应在现有理由中说清最小修订方向与复查终点，例如“恢复原文对离线方案的选择，同时保留其离线条件”，而非只说“再自然一些”。用现有 pattern、materiality_reason、preserved_function 和审查意见表达即可，不新增字段或要求每段都有问题。优秀原文可 keep_original，但不能以此豁免确有的重大残留；diagnosis_only 检查诊断是否正确识别问题并保护必要边界，不要求伪改稿。干净文本可以没有问题项，但仍需正面的通读证据和覆盖锚点。

审查者提出补充限定时须指出原文依据和缺失的实际功能，不能以“更安全”为由添加新的免责、风险或外推限制。原文可能存在事实或专业风险缺口时，在正文外交作者核实，不自行补写。已保留所有独立边界、恢复原有判断并解决可定位问题后，纯风格分歧不构成继续返修的理由。

每轮只修有明确锚点的实质问题；安全问题优先于风格偏好。没有可证明净改善时保留当前最优稿或原文，再按原有审查合同处理；最多五轮，不反复抛光成另一种模板腔。实质异议不能靠多数票忽略：核对后修复并新 attempt 重审，或以原文和候选证据驳回；仍不确定就不批准。
