# 机器味写作模式参考

只改表达，不改事实。先按 [自然写作原则](natural-writing.md) 理解思想与关系，再用本页诊断具体障碍。模式是线索，不是禁词表；词语、句法、段落和篇章的修改均需上下文理由，专业术语不因英文或代码出现而自动删除。

## 词语与常见句式

| 模式 | 处理 |
| --- | --- |
| 首先/其次/最后、因此/从而/进而连环使用 | 关系清楚时省略路标；判断和原因的顺序按内容决定 |
| “随着发展”“广泛关注”“重要理论意义” | 用原文已有的约束、缺口或对象替换；原文缺依据时不补事实 |
| “来源/支撑/抓手/赋能/闭环”等抽象标签 | 改成原文已有的具体对象、动作或关系，不凭空补出执行主体 |
| 括号套括号、长分号串、机械“研究表明…\cite{}” | 按语义负荷重组句流，保持引用与其主张的对应 |
| “不是 A 而是 B”“不只是 A 更是 B”等 | 真实区分保留，可调整句式但不削弱含义；伪对立把 B 放入主干；同义递进合并，不补事实 |
| “值得注意的是”“需要指出的是”、保持沉默、只是多想一次 | 直接写已有判断或来意；纯姿态或模型自我辩护合并/删除 |

## 边界声明压缩

遇到无效免责、假想反驳或审稿人预答辩时，按 [防御性表达五问](defensive-writing.md) 判断功能并记录去向；不另设禁词表。

“定义 + 多个否定排除项”可能把审查清单写进了正文。先检查原文是否已有可直接表达的对象、关系或行动，再判断哪些限定会改变解释：独立限定全部保留，没有每段数量上限。仅对能证明语义等价的同义限制合并表达，在内部处置表记录依据。彼此独立的范围、责任、承诺，以及专业文本中的阈值、分母、暂停条件，不得机械合并。下表的科研场景只是实例，不是通用润色的必经内容。

| 输入模式 | 处置 | 仍需保留 |
| --- | --- | --- |
| “本文所说的可比是……；不要求……也不等同于……” | 改为正向判据，并保留所有会改变解释的范围限定 | 原文已有的判据、对象和范围 |
| “本项目不证明 A，也不能推出 B，仍需验证 C” | 原文已有明确研究对象或动作时改为“本项目检验 X”；只有会改变 X 解释的限制留在正文 | 证据强度和外推边界 |
| 同段连续“不能证明/不等同于/仍需独立验证” | 合并同义限制，诊断中逐项记录去留 | 任何真实的科学二分 |
| “关系保持”与“临床获益”并列 | 用一条承接句说明前者是本段研究对象、后者是下游问题 | 二者不相互推出的边界 |

原文只有排除性边界时保留原句并标记人工确认。不要因为追求顺滑而删除阈值、分母、暂停/失败处理、探索性定位、规划资源边界或 LaTeX/数学/代码 token。

## 工程协议腔与规格书句法

- 入口/出口、状态映射、队列、载荷、闸门、终态、整包、静默补写、失败码等词连续出现时，恢复原文主体和动作；确属实现细节则保留；首次中文释义仅限原文已有可靠解释。
- 同句用分号、括号或冗长箭头同时列动作、配置、版本、失败和验收，造成阅读障碍时，保留必要字段，再按实际文体和读者需求组织；受保护结构下只调整句内自然语言，不拆行或搬移。字段若含阈值、权限、分母或失败处理不得删除。
- 连续“归入、映射、锁定、冻结、收缩、降级”却无行动主体时，补回原文已有主体，不新增职责。

## 术语与语域

| 类型 | 处置 | 示例 |
| --- | --- | --- |
| 受控术语 | 逐字保留 | `\texttt{RELEASE}`、`H_0`、统计量、模型名、接口字段 |
| 可保留术语 | 原文支持时首次释义，后文用稳定短称 | `manifest`、`fail closed`、参考包络 |
| 临时造词 | 优先改写；对象不确定则人工确认 | 四态终结、有界使用政策原型、纯暴露解释 |

混合语域可按原文采用“中文总括 + 必要英文括注”，不得改代码、数学、引用或状态 token。普通英文句子按自然语言润色，不把每个英文词当作受控术语。专业技术细节本身不是机器味。

## 章节去重与处置

- 建立“事实—首次完整定义—后续引用”表；冻结、污染、样本和边界规则可在首次位置完整说明，其他位置视独立阅读需要保留必需内容；不能证明重复无作用时保留或人工确认，默认不跨章节搬移。
- 每个候选项标为 `保留`、`改写`、`合并` 或 `人工确认`，写明理由和不可改变的含义。
- 按实际文体判断职责：文章关注观点或叙述推进，邮件关注来意与请求，报告关注判断与依据，说明关注理解和操作顺序。专业章节按原文职责处理，不自动附加基金写作路径。

## 安全不变量

只记录原文已有的事实、立场、人物关系、时间/金额、承诺、责任和条件；专业文本再核对状态/权限、阈值、分母、失败处理、探索性定位和资源边界。改写后做“原句—改写句—不变量”对照；无法证明时保留原句。

## 结构保护

`\cite{}`、数学公式、`\ref{}`、`\eqref{}`、环境、`\item`、注释和列表 token 必须逐字保持。
