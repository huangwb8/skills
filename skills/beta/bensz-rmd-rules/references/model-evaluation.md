# 临床预测模型全面评价指南（AI 执行规范）

## 1. 目的与执行原则

当用户要求开发、验证、比较或应用临床预测模型时（如疾病诊断、肿瘤分型、治疗响应、复发风险、生存预后预测），AI 应在用户授权的任务范围及现有数据、计算资源和研究条件允许的情况下，尽可能全面地评价模型，而非仅报告 AUROC、准确率或统计学显著性。

本指南不是强制完成所有分析的清单。优先完成与研究目标直接相关的核心分析；条件允许时主动补充其他有价值的分析。不得为了形式上的完整而开展不适用、统计效能不足或可能引入偏倚的分析。对于无法完成的项目，应说明原因、可能影响及后续完善所需条件，不得虚构结果或保证。

## 2. 分析前检查

- 明确目标人群、使用场景、预测时间点、结局定义、预测时间窗及模型预期支持的临床决策；区分二分类、多分类、生存和连续结局任务。
- 检查样本量、事件数、类别不平衡、缺失值、异常值、重复患者、批次效应、队列来源及数据代表性；条件允许时评估开发与验证所需样本量。
- 合理划分训练、调参、校准和测试数据；按患者或队列分组，避免重复样本跨集合。特征筛选、标准化、缺失值填补、降维、过采样、模型选择和阈值优化等数据依赖操作必须限定在适当的开发数据内，避免信息泄漏。校准及共形预测阈值不得利用最终测试结局确定。
- 优先设立合理的临床基线、现有成熟模型或简单统计模型作为对照；尽可能预先确定主要评价指标、临床阈值与可接受标准。

## 3. 评价维度与分析方法

| 评价维度 | 优先开展的经典或推荐方法 | 条件允许时补充 |
|---|---|---|
| 区分度 | ROC/AUROC、PR 曲线/AUPRC；生存任务采用 C-index、时间依赖 AUC | 多分类逐类及宏/微平均指标；配对模型比较 |
| 校准度 | 平滑校准曲线及置信区间、校准截距、校准斜率 | O/E 比值、Integrated Calibration Index；独立数据再校准并分别报告前后表现。避免仅依赖 Hosmer–Lemeshow 检验 |
| 分类性能 | 混淆矩阵、敏感度、特异度、PPV、NPV、准确率 | F1、MCC、Balanced Accuracy；临床相关阈值下的性能及错误类型分析 |
| 整体预测性能 | Brier Score、Log Loss；生存任务采用时间特异性 Brier Score、IBS；连续结局采用 MAE、RMSE | Brier Skill Score、R² 等任务适用指标；与简单基线比较 |
| 临床效用 | DCA（Decision Curve Analysis），比较模型、现行策略、全部干预与均不干预 | Clinical Impact Curve、期望效用分析、成本效益分析；阈值范围必须具有实际临床意义 |
| 增量预测价值 | 相对于临床基线或现有模型的 ΔAUROC/ΔC-index、ΔBrier Score、ΔNet Benefit 及置信区间 | 适用时采用 DeLong 检验、似然比检验；NRI、IDI 仅作审慎补充 |
| 不确定性与预测效率 | 共形预测（Conformal Prediction）：实际覆盖率、平均集合大小或区间宽度；分类任务报告单标签、多标签及空集合比例 | 多个目标覆盖率下的效率比较、单标签准确率、Risk–Coverage Curve、贝叶斯预测或模型集成；明确拒绝预测规则 |
| 亚组表现与可靠性 | 按临床重要亚组报告区分度、校准度、分类性能及置信区间 | 亚组净获益、Group/Conditional Coverage、最差亚组表现；检验分子状态相关的预测失败，注意小样本及多重比较 |
| 泛化能力 | Bootstrap 或交叉验证进行内部验证；尽可能实施独立外部验证 | 嵌套交叉验证、Leave-one-cohort-out、时间或地域外部验证、跨队列性能异质性与 Meta-analysis、前瞻性验证 |
| 鲁棒性与适用范围 | 针对实际数据质量与研究假设开展敏感性分析 | 缺失特征、测量噪声、批次、平台、患者构成及结局定义变化的压力测试；分布偏移与 OOD 检测 |
| 可解释性与科学价值 | 适合模型结构的系数、效应估计或特征贡献分析 | SHAP、Permutation Importance、ALE/PDP、消融实验、解释稳定性及独立生物学验证；不得将特征贡献直接解释为因果机制 |
| 临床转化与实施 | 评估目标场景、检测成本、耗时、失败率及实际可操作性 | 前瞻性静默部署、人机协作研究、临床影响研究、随机对照试验、医疗经济学评价、部署后漂移与安全性监测 |

## 4. 关键方法学要求

- **指标适配：** 根据结局类型和临床目标选择指标。类别不平衡时同时报告 AUROC、AUPRC 和事件比例；生存预测须处理删失，必要时处理竞争风险，明确评价时间点；连续结局重视误差、系统偏倚及预测区间。KM 曲线、Log-rank 检验及 HR 不能替代个体预测性能评价。
- **统计严谨性：** 尽可能报告主要指标的 95% 置信区间、效应大小和样本数；模型比较应尽量基于同一独立测试集，采用配对分析。重采样应反映患者、中心或队列的依赖结构。不要用单一 P 值或任意 AUROC 阈值判定模型是否可用。
- **共形预测：** 条件允许时，使用独立校准集开展 Split Conformal Prediction 等适用方法，在预设覆盖率（如 90%、95%）下同时评价实际覆盖率和预测效率。边际覆盖率不等于个体可靠性、分类准确率或亚组覆盖率；标准共形预测的保证依赖可交换性等条件，跨队列分布偏移时必须重新检验其适用性。Risk–Coverage Curve 的 coverage 指接受预测的样本比例，与共形预测覆盖率不同。
- **临床决策：** DCA 应对应真实可执行的临床行动及合理的错误代价，净获益并非已经证实的患者实际获益。仅有某种治疗的单臂数据时，预测治疗响应不等于预测相对于其他治疗的获益；治疗效应预测需要适当的比较数据和因果推断设计。
- **外部验证：** 最终验证数据应独立于模型开发、特征选择、参数调整和阈值选择；反复用于模型优化的外部数据不再是独立验证集。没有独立外部验证时，不得声称已经证明跨队列泛化或临床适用性。

## 5. 执行优先级与结果交付

1. **核心评价：** 数据质量与泄漏检查、合理内部验证、区分度、校准度、整体预测性能、适用的分类指标及置信区间。涉及临床决策时优先开展 DCA；有独立数据时优先进行外部验证；有成熟对照时进行增量价值比较。
2. **增强评价：** 数据允许时，尽量补充共形预测、选择性预测、亚组分析、跨队列异质性、鲁棒性分析及可解释性分析。
3. **转化评价：** 研究目标涉及实际临床应用且具备条件时，开展前瞻性验证、临床影响及实施可行性评价。若无法开展，应明确其为后续验证要求，而非宣称已完成。

交付时，应给出可复现的分析代码（使用用户指定的语言，或选择成熟工具）、主要图表、指标及置信区间、关键方法与参数、临床意义解读，并附评价完成情况表，将项目标为“已完成”“部分完成”“条件不足”或“不适用”，说明理由。不要在未经授权的情况下执行高成本或超出任务范围的扩展实验。

R 语言可优先考虑 `pROC`、`PRROC`、`yardstick`、`rms`、`riskRegression`、`survival`、`timeROC`、`dcurves`、`predictset`、`rsample`、`metafor`、`fastshap`、`shapviz`、`iml` 等工具；实际使用前核实包版本、接口及统计假设，不强制依赖特定软件包。

## 6. 最终综合判断

AI 应综合回答：模型是否具备预测能力？概率是否可信？是否具有相对于现有方法的增量价值和临床净获益？能否识别不可靠预测？是否在不同患者及独立队列中保持性能？是否具备临床应用所需的验证和安全证据？

根据实际证据区分“证据不足或存在重大缺陷”“具有初步预测价值”“具有外部验证支持”“具有潜在临床应用价值”和“具备进一步部署评估或特定场景应用所需的证据”。不得用简单加权总分掩盖数据泄漏、严重失校准、泛化失败或安全性问题。回顾性性能优秀不等于已经具备临床部署资格，最终还需结合预期用途、临床影响证据及适用的合规要求。

方法学上可参考 TRIPOD+AI（报告规范）、PROBAST+AI（偏倚风险及适用性评价）、DECIDE-AI（早期临床评价）、SPIRIT-AI 与 CONSORT-AI（临床试验规范）。本指南是面向 AI 执行的通用实践框架，而非上述指南的替代品。
