# 推断与报告

## 写之前先决定什么可以回答

每个关键问题写一行「判断 → 比较与分析单位 → 证据 → 结论边界」。推断前确定 estimand、效应尺度、对照、人群、缺失与排除、配对/聚类/时间结构和不确定性方法。跨队列或拟合与验证分离时查独立性、泄漏和患者层分母。观察、预测、因果各用相称证据，标出探索结果。

只有题目或数据时，主动找有用途且现有设计可检验的问题。反直觉结果先查口径和数据，再尽可能用对照或敏感性分析区分解释。缺乏相应证据时把机制留作假说。

尽量保留未经显著性筛选的完整估计表，含有效样本与事件数、估计与单位、适当的区间及置信水平、方法和状态。有合适检验与假设才给 p 值，多重检验写明比较族和调整。不可估计、未运行或不适用均注明原因。配对 AUROC 差应在共同可评分单位比较并报告各法覆盖，bootstrap 抽样单位与区间条件应符合设计。覆盖差异、单独区间或一个 p 值都不足以证明互换性。

## 组织成可以读完的证据链

开篇给与用途相称的判断。每个问题说明读者关心什么、对照能排除哪些解释、什么结果会改变判断。用真实代码交代配对、分组、分母或模型选择，用图展示方向、例外、异质性或不确定性，用短表给精确数字，用文字解释证据与结论。后续问题接住前项疑点，避免四种形式重复。

例如评估读数能否互换，可摘录配对代码，画差异和区间并标阈值，为影响选择的分层给精确分母。缺跨平台证据时，可保留现方案并说明改变判断所需的条件。

## 把完整研究写成论文式报告

新分析都写完整报告。先在授权内核对数据、完成主要分析和关键诊断并解读，再写讨论及摘要。按问题数量、复杂度及决策影响展开方法、诊断与解读，关键证据留正文，大表或长实现可入附录。篇幅以论证为准，无最低字数或图表配额。局部维护限于授权范围。

| 章节 | 内容 |
| --- | --- |
| 摘要 | [结构式摘要](#结构式摘要) |
| 引言 | 背景、实际决策或知识缺口、问题的价值、主要及补充问题。外部事实给可核实来源 |
| 数据与方法 | 输入、单位、纳入排除及实际分母、变量和时间口径、比较设计、方法与参数理由、会改变结果的代码 |
| 结果 | 按问题写明方法理由、实际代码、估计量级与方向、区间、例外和未估计的比较，解释关键图表 |
| 质量控制与数字核对 | 检查、实际数值或状态、异常影响及处理，数字可回查正式字段、生成代码、图表和分母 |
| 讨论 | 综合主要、补充和相反证据，交代替代解释、推断及外推边界、会改变判断的条件、带输入/方法/判据的下一步 |
| 可复现性 | 数据或版本来源、关键参数、代码入口、环境、正式重建与报告入口、产物获取及访问限制 |

主要结果用内联数字解释量级和可能的反例。按数据与目标选择诊断，例如先查个体分布再判断是否查单点影响，拟合与评估可能共享信息时查拆分独立性及预处理边界。稳健性、敏感性与验证分析写明改了什么、固定了什么、比较说明什么。缺输入或无法估计时写明原因与影响。

### 正式题名

YAML `title` 体现实际对象、目标和设计，让读者知道比较或评估了什么。能界定范围的队列、设计或方法写进主标题；问句限于实际回答范围，遵守用户指定题名或文体。结果确认后对照范围与结论，保留探索、模拟或单一任务验证的适用条件。例：「乳腺癌表达谱中固定参考 TSP 程序评分的基因缺失偏差与误差界」。

### 结构式摘要

正文证据齐备后定稿，按报告语言依次写四个明确标签，可用段首粗体。英文用 Background, Methods, Results, Conclusions。

- **背景**写问题的价值和分析目标。
- **方法**写实际设计、数据或人群、主要比较及方法。
- **结果**写主要发现、有效分母及适用的效应量和不确定性，内联 R 引用与正文一致的结果。不可估计或关键分析未完成时写状态与原因。
- **结论**回答背景问题，限于结果、设计及适用人群支持的范围。

### 科学质控要给证据

按设计查纳入与分母、ID 与单位、缺失排除、异常值、训练验证隔离、统计假设或性能范围、跨产物数字一致性。每项给对象、判据、实际结果及异常处置，区分通过、发现问题、未执行、不可判断与不适用。正文解释影响解读的异常，长报告可用 DT 表指明关键数字来源和位置。“已通过”或计划中的检查不能充当证据。[重建与 HTML 验收](delivery.md)

## 用例子建立直觉，再给出数学定义

关键难点可按「手算假例 → 真实定义 → 实际结果」解释。例如两人换路线前后用时为 25→30 和 40→40 分钟，配对变化 +5、0，平均 +2.5。标明是假设，例子只说明单位内比较，不能推断路线造成变化。

完整配对均值写作 $d_i = y_{i,1} - y_{i,0}$、$\bar d = n^{-1}\sum_{i=1}^{n}d_i$。前后值来自同一单位，$n$ 仅数有效配对，正值表示上升，沿用测量单位。公式与实际加权、变换和区间算法一致，区分指标定义、估计式和推断假设。用真实图表说明量级、个体反例、失访分母与不确定性。区间跨零不能证明等效。

对影响结论的概念，正文保留直觉、核心公式和解释，长推导可入附录。熟悉的指标无需逐个举例。公式的符号、分母和单位应能追到计算，类比只迁移相符的关系。Rmd 用 `$...$` 或 `$$...$$`，HTML 可用原生 MathML（`mathjax: null` 与 `pandoc_args: ["--mathml"]`）供现代浏览器离线阅读。

## 代码怎么展示，数字怎么引用

主要代码块前说明所用数据、影响比较的特点、选法或参数的理由、输出能回答什么。代码贴近对应结果。图表后用 Markdown 解释发现和证据边界。禁止代码依据统计量生成、拼接或选择结果解读、讨论和结论句子。代码只填数字、组名、可估计状态等可核验事实，计算或数据变化后按新证据复核文字。

| 代码 | 显示与执行 |
| --- | --- |
| 分组、配对、分母、指标、拟合、重采样、诊断、稳健性 | 正式计算交给 targets。实际关键片段默认展开，长实现可折叠并链接源码 |
| 图表与展示值 | 绘图、制表代码默认展开，常规样式可隐藏。Rmd 可读取、筛选、排序、格式化并核对正式结果 |
| 包载入、路径配置、重复排版 | 通常隐藏，只做渲染所需的工作 |

HTML 默认 `code_folding: show`，长块可设 `class.source = "fold-hide"`。`echo = FALSE` 隐藏源码，`eval = FALSE` 展示摘录但不执行。摘录取自本次正式实现并链接可访问源码，保留既有项目或用户明确要求的可见性。

正文、摘要与图注的关键分母、效应、不确定性和阈值默认用内联 R 引用命名结果或其展示值。内联只取值或格式化，复杂筛选、统计和分支预先定义。正文、表和图共用结果及展示值，正文按需舍入，正式结果保留原精度。文献数字和假例标明来源或性质；固定快照尽量读入后内联，必须手引时写清来源和位置。

```markdown
完整配对为 `r pair_count`，平均变化为 `r mean_value` 个测量单位，
`r confidence_label`：`r interval_value`。
```

## 用 DT 展示报告表格

正文短汇总、附录与长宽明细均用 `DT::datatable()`，声明 `DT` 依赖。短表可用 `options = list(dom = "t", paging = FALSE, ordering = FALSE)`；明细按需启用搜索、排序、分页或 `scrollX`。chunk 直接或显式输出 widget，循环和折叠区须在浏览器复核。标明单位、精度、分母、缺失及特殊编码。[主题与图表](visuals.md)

展示子集时说明选择标准和范围，分页不会减少客户端下载。过大或无嵌入授权时用文字或获准的 DT 汇总，完整明细按授权单独交付。

骨架默认用 DT 渲染正文汇总。加 `--detail`（兼容 `--dt`）追加[逐单位配对明细](../templates/detail/appendix.Rmd)，读取正文已有的 `paired_changes`，展示差值与纳入状态。换真实数据前确认 HTML 嵌入逐条记录及单位编号的授权。
