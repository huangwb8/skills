# 推断与报告

## 写之前先决定什么可以回答

开写前选出影响主要决定的判断及其来源。没有预设时说明分析性质和经验判据来历。用「判断 → 比较与分析单位 → 正式证据及正文位置 → 结论边界」标明开发、留出确认、部署检验或探索诊断。记录未运行、不可估计、方案改变、未达门槛或不适用的原因与影响。正文可自然组织。

推断前确定 estimand、尺度、对照、人群、缺失与排除、配对/聚类/时间结构及不确定性。查跨队列及训练验证独立性、泄漏和患者层分母。首次定义时说明谁被留出、阶段和用途。患者留出与同次测量的基因留出可检验内部关系。独立重测和临床终点各需对应观察。分别给样本出分、全请求可评分和共同可评分的分母。观察、预测、因果各用相称证据。

只有题目或数据时，主动找有用途且现有设计可检验的问题。反直觉结果先查口径和数据，再尽可能用对照或敏感性分析区分解释。缺乏相应证据时把机制留作假说。

尽量保留未经显著性筛选的估计表，含有效样本和事件数、估计及单位、区间和置信水平、方法与状态。有适当假设才给 p 值，多重检验说明比较族及调整。配对 AUROC 差用共同可评分单位，并报各法覆盖。bootstrap 单位和区间条件须符合设计。覆盖差异、单独区间或一个 p 值均不足以证明互换。

## 组织成可以读完的证据链

开篇给与用途相称的判断。每节说比较的问题、改变与可比条件，紧接效应、区间、门槛及联合判定。点估计达标而区间越界时，说明证据不足以通过。分清跨档点估计范围和单档区间，交代各档基线。图示方向、例外或不确定性，短表给精确数与可懂的指标名及单位，正文解释决策含义，明细从对应入口查阅。逐项回答标题承诺的问题，让后续问题接住前项疑点。

例如评估读数能否互换，可摘录配对代码，画差异和区间并标阈值，为影响选择的分层给精确分母。缺跨平台证据时，可保留现方案并说明改变判断所需的条件。

## 把完整研究写成论文式报告

在授权内核对数据、完成主分析与关键诊断，再写讨论和摘要。按问题复杂度与决策影响展开，主证据留正文，长表和长实现可入附录。无最低字数或图表配额。

| 章节 | 内容 |
| --- | --- |
| 摘要 | [结构式摘要](#结构式摘要) |
| 引言 | 背景、实际决策或知识缺口、问题的价值、主要及补充问题。外部事实给可核实来源 |
| 数据与方法 | 输入、单位、纳入排除及实际分母、变量和时间口径、比较设计、方法与参数理由、会改变结果的代码 |
| 结果 | 按问题写明方法理由、实际代码、估计量级与方向、区间、例外和未估计的比较，解释关键图表 |
| 质量控制与数字核对 | 检查、实际数值或状态、异常影响及处理，数字可回查正式字段、生成代码、图表和分母 |
| 讨论 | 综合主要、补充和相反证据，交代替代解释、推断及外推边界、会改变判断的条件、带输入/方法/判据的下一步 |
| 可复现性 | 数据或版本来源、关键参数、代码入口、环境、正式重建与报告入口、产物获取及访问限制 |

主要结果用内联数字交代量级和反例。按目标选诊断，如个体分布、单点影响、拆分或预处理边界。稳健性、敏感性与验证沿用上述比较口径。

临床预测模型报告按[评价指南](model-evaluation.md)交代用途、预测时点和时间窗、结局、队列与验证方式。报告与目标相符的主要指标、置信区间和实际分母，说明结果支持哪些预测、外推或临床应用判断。交付评价完成情况表，用 `DT::datatable()` 标注「已完成」「部分完成」「条件不足」「不适用」，并说明理由、影响及适用的补足条件。任务只覆盖既有报告的一部分时，按本轮范围核对或更新受影响的结果、状态与结论。

### 正式题名

YAML `title` 写明对象、目标和设计，可纳入界定范围的队列或方法。问句限于实际回答，遵守指定题名或文体。结果确认后复核探索、模拟或单一任务的适用范围。例「乳腺癌表达谱中固定参考 TSP 程序评分的基因缺失偏差与误差界」。

### 结构式摘要

正文证据齐备后定稿，按报告语言依次写四个明确标签，可用段首粗体。英文用 Background, Methods, Results, Conclusions。

- **背景**写问题的价值和分析目标。
- **方法**写实际设计、数据或人群、主要比较及方法。
- **结果**写主要发现、有效分母、效应与不确定性，保留决定解释的比较条件（如同输入、同维或保留高维）。内联 R 引用正文同源结果。关键分析不可估计或未完成时写状态及原因。
- **结论**回答背景问题，限于结果、设计及适用人群支持的范围。

### 科学质控要给证据

核对纳入与分母、ID、单位、缺失排除、异常值、训练验证隔离、统计假设或性能及跨产物一致性。写对象、判据、实测状态和处置，区分通过、发现问题、未执行、不可判断与不适用。正文解释影响解读的异常，长报告可用 DT 标关键数字来源。“已通过”或计划不能充当证据。[重建与 HTML 验收](delivery.md)

## 用例子建立直觉，再给出数学定义

关键难点可按「手算假例 → 真实定义 → 实际结果」解释。例如两人换路线前后用时为 25→30 和 40→40 分钟，配对变化 +5、0，平均 +2.5。标明是假设，例子只说明单位内比较，不能推断路线造成变化。

完整配对均值写作 $d_i = y_{i,1} - y_{i,0}$、$\bar d = n^{-1}\sum_{i=1}^{n}d_i$。前后值来自同一单位，$n$ 仅数有效配对，正值表示上升，沿用测量单位。公式与实际加权、变换和区间算法一致，区分指标定义、估计式和推断假设。用真实图表说明量级、个体反例、失访分母与不确定性。区间跨零不能证明等效。

正文保留难点的直觉、公式、符号、分母和单位，沿实现核对。可把长推导移入附录，熟悉指标无需逐个举例，类比只迁移相符关系。Rmd 用 `$...$` 或 `$$...$$`，原生 MathML（`mathjax: null` 与 `pandoc_args: ["--mathml"]`）支持现代浏览器离线阅读。

### 冻结坐标的例子

比较同一冻结模型中同一人在高覆盖与遮挡后的坐标，只改变推理输入。若三人的坐标从 0、1、2 一起右移 0.5，人与人之间的距离不变，每个人的绝对位置却都变了。这个假例的归一化漂移约为 0.61。正式定义在两次都能出分的患者中计算，记高覆盖坐标为 $h_i$、遮挡后为 $z_i$，$\bar h$ 为这些患者的高覆盖中心，$n$ 为配对人数：

$$
\frac{\operatorname{median}_{i}\lVert z_i-h_i\rVert_2}
     {\sqrt{n^{-1}\sum_{i=1}^{n}\lVert h_i-\bar h\rVert_2^2}}.
$$

分子是患者移动距离的中位数，分母是高覆盖坐标到中心的均方根距离。两套矩阵按同一患者顺序排列，正式实现还要求配对数大于邻居数加一，且半径为正。下面摘录计算部分，省略同一块内的几何诊断。

```r
drift <- NA_real_
keep <- rowSums(!is.finite(high)) == 0 & rowSums(!is.finite(z)) == 0
n_paired <- sum(keep)
if (n_paired > cfg$neighbors + 1L) {
  h <- high[keep, , drop = FALSE]
  za <- z[keep, , drop = FALSE]
  radius <- sqrt(sum(scale(h, center = TRUE, scale = FALSE)^2) / nrow(h))
  if (radius > 0) drift <- median(sqrt(rowSums((za - h)^2))) / radius
}
```

用 `relative_drift` 列报告漂移。案例四队列的比值为 0.53–1.11，均超过预设容差 0.25；同时样本出分率为 100%，前十近邻重合率为 83.5%–95.3%。它们分别回答绝对位置、模型能否出分和局部关系。结论限于这批冻结包、确认队列与遮挡；按训练标准差报告的逐轴误差另有名称和单位。

## 代码怎么展示，数字怎么引用

从报告中的成品回溯本次实际运行的实现。代码块前交代输入来源、数据单位及这步回答的问题，块后指向图中的点、线、区间或表中的具体行列。共用流程展示一次，在相关结果旁链接到报告中展示实现的小节。重点展示会改变读数或判断的操作。

- **主图。** 指明用于绘图的数据集、分析结果或 target、每个观测单位和实际使用的列。交代影响读数的筛选、汇总或变换，并展示真正构图的代码，例如实际的 `ggplot()`、`aes()`、图层及用到的统计变换或分面。图若由独立流程导出，可直接嵌入图片，同时展示实际生成它的代码片段。`print("xxx.jpg")`、`knitr::include_graphics()` 或 `print(p)` 只能负责呈现。
- **关键表格。** 展示决定数字的分组、分母、指标、估计或汇总代码，并指出代码输出对应哪一行或列。配对示例用 `is.finite()` 筛出有效差值，`length(changes)` 给出分母，点图随后直接绘制这些差值。`DT::datatable(summary_table)` 负责交互展示。[配对报告示例](../templates/project/01.01.01-paired-change.Rmd)
- **核心模型。** 指明样本从哪里来、纳排规则、分析单位、结局和预测变量。展示构建样本、切分或重采样、拟合与验证中实际执行的关键代码。给出本次实际生效的模型公式或设置、参数值及来源，包括实际使用且影响结果的默认值、随机种子和调参后的值。说明预处理与调参在哪些样本上拟合、每次验证用哪些样本评估、验证指标怎样得到，以及报告结果对应哪个拟合对象或预测产物。复用既有模型或预测时，交代其来源、版本和可追溯的开发或验证证据。没有运行内验证时，写明实际状态。`print(res)`、`summary(model)` 或单独展示存盘对象只说明怎么查看结果。

| 代码 | 显示与执行 |
| --- | --- |
| 分组、配对、分母、指标、拟合、重采样、诊断、稳健性 | 正式计算交给 targets。实际关键片段默认展开，长实现可折叠并链接源码 |
| 图表与展示值 | 展示实际构图或生成表格数字的关键片段。常规取数、打印、导出和样式可隐藏 |
| 包载入、路径配置、重复排版 | 通常隐藏，只做渲染所需的工作 |

让读者打开 Rmd 后能按顺序运行或调试关键代码。交代工作目录、环境、需要先执行的代码块、输入对象和参数从哪里来，以及运行后可检查哪个中间对象。依赖自定义函数时，给出该函数的关键实现和可访问的源码位置。能直接生成轻量图表的代码块可在渲染时执行。长时拟合和验证继续由 `targets` 执行，Rmd 可用 `eval = FALSE` 展示对应的真实片段，并提供能手动运行的调用或正式重建入口。摘录须与本次实际运行版本一致。

HTML 默认 `code_folding: show`，关键片段展开，较长的上下文可设 `class.source = "fold-hide"`。用 `echo = FALSE` 隐藏辅助代码时，在 Rmd 中保留读者需要的初始化步骤。保留既有项目或用户明确要求的可见性。上游实现确实不可查时，展示获准核验的取数、筛选与映射，说明可以从哪一级汇总开始复核。可用公开或合成的最小输入帮助读者运行同一关键步骤，并清楚标明其性质和与正式结果的关系。

正文、摘要与图注的关键分母、效应、不确定性和阈值默认内联命名结果或共享展示值。内联只取值或格式化，复杂筛选、统计与分支预先定义。解读、讨论和结论直接写入 Markdown，禁止按统计量自动生成或切换这些文字。数字变化后复核文字。展示可舍入，正式结果保留精度。标注文献数字及假例来源或性质。固定快照尽量读入后内联，手引须指明来源和位置。

```markdown
完整配对为 `r pair_count`，平均变化为 `r mean_value` 个测量单位，
`r confidence_label`：`r interval_value`。
```

## 用 DT 展示报告表格

正文短汇总、附录与长宽明细均用 `DT::datatable()`，声明 `DT` 依赖。短表可用 `options = list(dom = "t", paging = FALSE, ordering = FALSE)`；明细按需启用搜索、排序、分页或 `scrollX`。chunk 直接或显式输出 widget，循环和折叠区须在浏览器复核。标明单位、精度、分母、缺失及特殊编码。[主题与图表](visuals.md)

展示子集时说明选择标准和范围，分页不会减少客户端下载。过大或无嵌入授权时用文字或获准的 DT 汇总，完整明细按授权单独交付。

骨架默认用 DT 渲染正文汇总。加 `--detail`（兼容 `--dt`）追加[逐单位配对明细](../templates/detail/appendix.Rmd)，读取正文已有的 `paired_changes`，展示差值与纳入状态。换真实数据前确认 HTML 嵌入逐条记录及单位编号的授权。
