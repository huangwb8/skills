# 计算、环境与重建

正式研究分析统一用 `targets` 管理计算、用 `renv` 锁定依赖、用 Rmd 交付完整报告。算得快的研究可以用一张小的依赖图；耗时的研究按科学阶段、队列或重采样任务拆分，按资源和局部失效范围决定粒度。已有 targets 与 renv 的项目沿用自己的入口与目录。其他项目如需新交付，可在独立目录接入获准的只读输入、已有算法和可核验结果；迁移原项目需授权。

## 项目布局

| 路径 | 职责 |
| --- | --- |
| `00.Environments/` | `environment.R` 集中确定依赖库；`packages.txt` 声明所需 R 包；`renv.lock` 锁定环境；`analysis.R` 演示一份独立、受版本控制的分析设置 |
| `raw/` | 保护真实输入和唯一来源快照；随骨架附上的 CSV 都是合成样例 |
| `R/`, `_targets.R`, `_targets/` | 正式计算函数、依赖图、可重建的 store；骨架的 `R/paired.R` 示范配对、估计和稳健性诊断 |
| `products/`, `reports/` | 可复用的科学结果；单独交付的图、表和补充附件 |
| `scripts/tests/`, `tmp/tests/<run-id>/`, `tmp/scratch/` | 按需放入项目测试、独立运行副本和探索产物 |
| `run.R`, `01.01.01-paired-change.Rmd`, `01.01.01-paired-change.html` | 起步入口和报告。显式传入其他 Rmd 路径也可渲染，HTML 默认与所选 Rmd 同名并位于同一目录 |

目录按需创建。用户已有的合法布局优先。正式输出与输入、环境、测试和 store 分开。正式入口从项目根运行，R chunk 中的相对路径以项目根为准；HTML 中的相对链接以 HTML 所在目录为准。生成的样例会随报告目录调整链接；若只交付 HTML，还需一并提供允许交付且报告引用的附件。

## 环境生命周期

骨架需要 R、Pandoc 及在宿主 R 库显式安装的 `renv`。从项目根运行：

- `Rscript --vanilla run.R prepare`：为新项目安装已声明的包及依赖到项目库，生成 `00.Environments/renv.lock`。锁文件已存在时中止。
- `Rscript --vanilla run.R restore`：使用锁文件记录的 R 版本恢复项目库。恢复需要可用的软件源、包缓存或当地镜像。
- `Rscript --vanilla run.R update-lock`：经审阅后更新依赖并重写锁文件；在恢复旧结果时用 restore。
- `Rscript --vanilla run.R build`：先让 targets 更新缺失或失效的结果，再渲染完整报告。
- `Rscript --vanilla run.R report`：检查报告所需的 target 仍有效，读取结果并渲染。可给 build/report 传一个项目内的 Rmd 路径；工作目录仍以项目根为准。

`renv/` 的项目库默认在 `00.Environments/` 下，库和下载缓存可重建；将包声明、锁文件、环境入口和分析设置纳入版本管理。模板通过显式入口选择项目库并核对锁定版本，普通 compute/render 不触发安装。根据数据和方法记录 renv 不管理的前提：R 发行版、Pandoc、系统库、编译器、外部资料版本和必要的字体/locale。默认 CRAN 用于演示；真实项目可依实际包来源显式配置软件源和复原方式。

## 把结果放在对的层

- 按科学阶段定义 targets：保护原始输入，记录纳入与排除，再计算估计、诊断与稳健性分析。把外部文件和参数文件声明为 `format = "file"`，从 `R/` 显式加载函数，按需把软件环境及锁定版本纳入失效判断。外部资源和固定汇总按可核验的快照、版本或校验和引入，保留来源和适用范围。
- 报告通过 `targets::tar_read()` 读取正式结果，用内联 R 引用数字，展示真实源代码摘录并执行必要的取数、绘图、格式化和一致性核对。读前用同一脚本、同一 store 及所需结果检查 `tar_outdated()`，保持依赖遍历；检查会解析 DAG，DAG 声明部分应可安全读取。缺失、损坏或失效时提示正式构建；报告层没有另一套计算或缓存入口。
- 需要独立交付的模型、表或图可从正式入口导出。对每项关键结果写明输入/版本、参数、生成它的代码或 target、结果位置及重建命令；遇到难以重做的来源先把可复核材料保存下来。
